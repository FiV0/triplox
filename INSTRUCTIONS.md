You are in the Triplox CODE repository. There is an ISSUES.md file at the root of the repository.

Objective: Go through every issue in the ISSUES.md file and fix the issue one commit at at time.

Process:
1. Create a list of the issues that you can tick off at the end of ISSUES.md.
2. Pick the the first item that has not been done.
3. Investigate thoroughly what the fix should be and how it should be done. Make sure you are not overengineering a simple fix.
4. Do the work.
5. Commit and clearly describe what you did for that particular fix.
6. Tick the item of the list.
7. Repeat from step 2 onwards until no further issue needs to be addressed.

When finding other issues during an investigation. Add them to the ISSUES.md file, but don't do them immediately. Separate things
clearly by commits.
